# Radar de Estudos — Concursos

Sete Agent Skills dedicadas a concursos brasileiros, priorizando nível médio e fontes oficiais gratuitas.

Arquivos: `.agents/skills/<nome>/SKILL.md` e `estudos-concursos/PROMPTS_PRONTOS.md`.

**Isolamento:** esta branch no repositório central-aprovacao é experimental. Não modificar NinjaScript, robôs, Fusion, Risk Desk ou o AGENTS.md principal. Não fazer merge na main sem aprovação.

**Uso:** no Codex, abrir esta branch e verificar a descoberta de skills; arquivos GitHub não tornam skills automaticamente disponíveis em qualquer conversa do ChatGPT. Na conversa, os prompts podem ser usados diretamente.
